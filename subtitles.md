## Embedding subtitles in video playback in a Media Panel

A brand new feature in v2.0 is the ability to embed subtitles live in a Media Panel while playing the video.

### Using an already generated SRT file

This feature works by attaching a specific subtitle file that has already been generated and matches the Project to a specific media player.
With multiple Media Panels open, one can attach independent subtitles to each Media Panel, so that it is possible to have English in one, the native language in another, and comments in a third.

First one has to generate an SRT file.
Luckily that is possible in DOTE from your DOTE transcript provided the transcript does not have major errors.

Give the generated SRT file a useful name.
Given that it is frozen image of the transcript when the export took place, it is recommended to add a useful name plus a date- and timestamp, eg. `subtitles-Lego Demo Transcript (Jeffersonian)-3.3.2026-12:45`
We use such examples in the [Lego Demo Project](demo.md) that you can try out.
They are stored in the Project folder that is created when you import the Demo Project.

It is best to store the generated subtitle file in the Project folder, but you can store it anywhere as long as it is available to DOTE during playback.
