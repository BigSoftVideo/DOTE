## What information can be found about a _DOTE_ Project?

The Project & Transcript Information panel assembles a range of helpful data about the currently open Project, including:

- Directory links
- Media Files
- Transcript Statistics
- Clips & Annotations
- Sync-codes
- Video-cues
- Checkpoints
- Autobackups
